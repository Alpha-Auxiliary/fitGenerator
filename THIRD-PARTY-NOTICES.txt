fitGenerator third-party notices
================================

This is a human-maintained inventory of direct runtime dependencies declared by
the native Windows, Android, and Rust-core projects. It is not a substitute for
the license texts shipped by upstream projects or for the release SPDX SBOM.

Repository status on 2026-08-11
--------------------------------

The repository does not currently contain core-rust/Cargo.lock, a generated
fit-generator-sbom.spdx.json, or built release artifacts. Consequently, exact
resolved versions, transitive dependencies, platform runtime files, and their
license texts have not yet been verified. Release CI must generate and review
the lock/resolution data and SPDX SBOM before publishing. The release verifier
rejects a bundle that has no nonempty SPDX SBOM.

Compiler-selected Rust standard-library/runtime code may also be embedded in
the native libraries. The Rust project is distributed under MIT OR Apache-2.0,
with additional third-party notices; the exact toolchain bundle must be captured
by release provenance and the SPDX SBOM:
  https://github.com/rust-lang/rust

The jni dependency is optional in the manifest and is enabled for the Android
JNI build. The fit-generator-core crate itself declares MIT in Cargo.toml.
Development-only dependencies are not included in this runtime list.

Explicit exclusion
------------------

Garmin.FIT.Sdk is not a dependency of the native Windows application, Android
application, or Rust core and must not be included in native release artifacts.
FIT encoding for these artifacts is implemented by the repository's Rust core.

No license text is reproduced here. Distributors must retain the exact upstream
licenses, copyright notices, and generated SBOM that apply to the resolved
release bundle.
